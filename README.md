# SEM-for-Road-User-Behavior
## Measurement model (CFA): overview

**What this step is for.** The survey measures attitudes, norms, habits,
intentions and behaviour with several questions each (for example, six
questions on attitude). Before we can test how these concepts relate to each
other (hypotheses H1–H7), we have to show that each group of questions really
measures one concept, and that the concepts are distinct from one another.
That is what a confirmatory factor analysis (CFA) checks.

**What we expect (the measurement hypotheses).**
1. The questions of each scale reflect one underlying concept.
2. Each question is a good indicator of its own concept and not of others.
3. Each scale is reliable.
4. The concepts are empirically distinct: attitude, perceived control and
   habit, for example, should not be the same thing in the data.
5. The model as a whole fits the data acceptably.

**How it is done.** Cyclists, pedestrians, drivers and motorcyclists are
analysed separately, because each group answered its own version of the
questionnaire. Answers are treated as ordered categories (1–5), not as
numbers. Each scale is first tested on its own; then related scales are
tested together; finally all concepts needed for H1–H7 are tested in one
model. The script reports, for every model, how well it fits, how strongly
each question relates to its concept, how reliable each scale is, and
whether the concepts can be told apart.

**What we found so far.** Most scales hold together and are reliable. A few
questions do not fit their scale (notably helmet/seatbelt use within risky
behaviour, and one enforcement question). The main problem is that attitude,
perceived control and habit are so strongly related that they cannot yet be
separated. The likely reason is the questionnaire design: the same
behaviours (alertness, speed, phone use, helmet or seatbelt) are asked about
in every scale, so answers about the same behaviour hang together regardless
of which concept the question belongs to.
